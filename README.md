# David Leal - Portfolio Website

A modern, responsive portfolio website showcasing David Leal's skills and projects as a web developer.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with smooth animations
- **Contact Integration**: Direct links to email, GitHub, and LinkedIn
- **Project Showcase**: Featured projects with technology tags
- **Skills Section**: Comprehensive overview of technical capabilities

## Sections

- **Header**: Personal branding with contact links
- **About**: Professional background and philosophy
- **Skills**: Technical skills organized by category
- **Projects**: Featured work with descriptions and tech stacks
- **Contact**: Multiple ways to get in touch
